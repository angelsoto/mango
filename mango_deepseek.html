Part 2.4: Error Prevention

Recipes

ViolationDetectionFix
Vivid color for body textContrast ratio <4.5:1Switch to muted equivalent
Adjacent gradient sectionsTwo --grad-* within viewportSeparate with Level 0 or 1
Red icon on white--mango-red-vivid in iconsUse --ink or --ink-2
Animated countertransition on number changeStatic number or progress bar
Exclamation point in headlineText content scanRemove, use period
"Revolutionary" in copyKeyword scanReplace with specific capability
Pure white backgroundbackground: #fffUse --base
Missing focus indicator:focus style checkAdd 2px --mango-yellow outline
Auto-playing carouselsetInterval detectionRemove auto-advance

New Component Checklist

☐ Uses only canonical tokens
☐ Respects color mode inheritance
☐ Semantic colors only for success/warning/error
☐ Motion respects reduced-motion
☐ Focus state visible and yellow
☐ Disabled state meets contrast (4.5:1)
☐ Tested in both muted and ripe modes
☐ No exclamation points in labels
☐ No "will transform" language
☐ No hex values outside tokens
