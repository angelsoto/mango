Spec + Recipes · Version 1.0

Mango Management Visual System

One token set, two registers: a muted mango palette for everyday reading, and a restricted "ripe" palette reserved for results, energy moments, and presentations. Every page recipe below inherits muted by default and opts into ripe deliberately, section by section.

1.3 Chart.js theme

2.4 Error prevention

Common violations

Caught in review, not in production — most of these are one CSS custom property away from correct.

ViolationDetectionFix
Vivid color for body textContrast <4.5:1Switch to muted equivalent or increase size
Adjacent gradient sectionsTwo --grad-* in viewportSeparate with level 0 or 1
Red icon on white--mango-red-vivid in iconUse --ink or --ink-2
Animated countertransition on numberStatic number or progress fill
Exclamation in headlineText content scanRemove, use period or nothing
"Revolutionary" in copyKeyword scanReplace with specific capability
Pure white backgroundbackground: #fffUse --base
Missing focus indicator:focus style checkAdd 2px --mango-yellow outline
Auto-playing carouselsetInterval detectionRemove auto-advance
